# Coding Standarts

Here are some coding standarts I follow for myself to keep all code cleany meany and very readable. Atleast for myself.

## 🟧 Commenting

Method describing comments shall always be in style of the following
```PHP
/**
 * This is a method's comment.
 *
 * @return string
 */
```

while being inside a method, for better readability and slimmer function body overall, I want to use the following

```PHP
# A small comment for better readability inside a method!
```

This only applies to describing comments, not type assigning comments.
